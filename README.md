# Life in the UK -> Mock Exam

An interactive practice app for the UK "Life in the UK" citizenship test.

- **720 questions** across **30 practice tests** of 24, written from the official 3rd-edition handbook *Life in the United Kingdom: A Guide for New Residents*.
- Take a numbered test, a **random 24** from the whole bank, or **practise by topic** (History, Society & culture, Government & law, What is the UK?, Values & principles).
- 45-minute optional timer, pass mark 18/24, full review with an explanation for every question.
- Light and dark mode.

## Use it

`index.html` is a single, self-contained page - open it in any browser, or enable **GitHub Pages** (Settings → Pages → deploy from the `main` branch root) to host it online.

## Files

- `index.html` - the playable quiz (all questions embedded).
- `questions.json` - the question bank as data (`t` test, `q` question, `o` options, `a` correct index, `e` explanation, `c` topic).

Questions deliberately avoid facts that have changed since the handbook was published.
